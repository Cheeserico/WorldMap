# Easy Effect Viewer 　 Read Me

Easy Effect Viewer は、Unity エディタ拡張ツールです。
ParticleSystem や VFX Graph エフェクトを効率的に管理・プレビューできます。

A Unity Editor extension tool for efficiently managing and previewing ParticleSystem and VFX Graph effects.

**使い方**: メニューバーから `Tools > EffectViewer > Viewer` を開いて、エフェクトのプレビューを表示できます。(ショートカット: `Ctrl+Shift+E` / `Cmd+Shift+E`)

**How to use**: Open `Tools > EffectViewer > Viewer` from the menu bar to preview your effects. (Shortcut: `Ctrl+Shift+E` / `Cmd+Shift+E`)
